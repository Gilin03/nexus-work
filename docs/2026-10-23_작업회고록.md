## 2. 세부 구현 내역

### 1) DB 포트 원천 격리 & 범용 IP 차단 REST API 구현 (커밋 `ccc0cc6`)
- **배경:** n8n이 MySQL 3307 포트로 직접 연결할 경우 외부 포트를 개방해야 하므로 심각한 보안 홀 발생. 이를 해결하기 위해 기존 웹 포트(5070)를 통과하는 Bearer 토큰 기반 REST API 구축.
- **엔드포인트:**
  - `POST /internal/api/v1/blocked-ips`: IP 차단 등록 (`ip`, `reason`, `minutes`, `created_by`)
  - `POST /internal/api/v1/blocked-ips/unblock`: 차단 해제 (POST 방식)
  - `DELETE /internal/api/v1/blocked-ips/<ip>`: 차단 해제 (RESTful 경로)
  - `GET /internal/api/v1/blocked-ips`: 활성 차단 목록 조회
- **보안 장치:**
  - 루프백 주소(`127.0.0.1`, `::1`) 오차단 원천 차단 (`400 Bad Request`)
  - 토큰 지문(`token_fp`)만 감사 로그에 기록하여 토큰 유출 방지
  - CSRF 토큰 검사 대상에서 토큰 기반 REST API 분리

---

### 2) 탐지 룰 전용 자동 차단 API 병합 (PR #5 / 커밋 `36c44c1` & `602cd01`)
- **기능:** 팀원(Gilin03)이 구현한 NEXUS R5/R6/R8 전용 자동 격리 엔드포인트 `POST /internal/api/v1/ip-block`.
- **엄격한 규칙 검증:**
  - 룰 매핑: R5(`account_spray`), R6(`post_lock_retry`), R8(`web_path_scan`)
  - 차단 시간: 1분 ~ 15분 범위로 엄격 제한
  - 화이트리스트 보호: `127.0.0.1`, `192.168.3.10`(포털 서버), `192.168.3.11/14/15`, `::1`
  - IPv4-Mapped IPv6 주소 변환(`::ffff:192.168.3.10` 방어)
  - Python 불리언 타입 가드(`isinstance(duration, bool)` 체크)
